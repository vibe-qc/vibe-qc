# Periodic GDF fixed-density reference

`si_gamma_fixed_density.npz` contains independent PySCF 2.6.2 S, Hcore,
Hcore-occupied density, Coulomb J, bare exchange K and Ewald-corrected K.
The JSON records the exact atom positions, lattice rows, contracted Gaussian
basis inputs, source checksums and vq job `bec400d255f3`. These are calculated
numerical data from the project's already-bundled pob-TZVP-rev2 and
def2-svp-jk basis sets, not copied program source.

The cell is Si diamond, conventional lattice constant 5.431 Angstrom,
44 orbital and 256 auxiliary functions, Gamma sampling, 28 electrons.
PySCF RSGDF used unit-square-normalized auxiliary functions,
`exp_to_discard=0`, `omega=omega_j2c=0.6`,
`precision_R=precision_G=1e-11`, `precision_j2c=1e-13`,
`j2c_eig_always=True` and `linear_dep_threshold=1e-9`.
The density occupies the 14 lowest eigenvectors of Hcore in the S-orthogonal
subspace (S eigenvalues above `1e-8`), with occupation two. Matrices use
PySCF AO order; the test explicitly maps p=(px,py,pz) to libint's
p=(py,pz,px) order. No fitted or reference energy is regenerated by vibe-qc.

To regenerate, run PySCF in a separate process through `vq`, construct
`pyscf.pbc.gto.Cell` with the JSON's exact Gaussian records, `unit='Bohr'`
and `precision=1e-11`, then evaluate `RSGDF.get_jk` at the stored density
with `exxdiv=None` and `exxdiv='ewald'`. Persist all components before any
SCF. The producing job later stopped on an unrelated PBE grid construction;
these fixed-density arrays had already been completed. They provide no PBE,
CaO, multi-k SCF or whole-route completion claim.

The slow regression compares the native SR/LR source at two split parameters
with these independent matrices and energy contractions. Relevant methods:
Sun et al., JCP 147, 164119 (2017), DOI 10.1063/1.4998644;
Ye and Berkelbach, JCP 154, 131104 (2021), DOI 10.1063/5.0046617;
PySCF 2, DOI 10.1063/5.0006074. Citation entries already exist in the
project citation database.

`nacl_ecp_reference.npz` and its JSON/TOML records contain independent
NaCl/LANL2DZ Gamma KRHF references at Cl z displacements 0 and 0.17 bohr.
The conventional lattice constant is 5.64 Angstrom. The generator converts
the bundled `.ecp` sidecar to NWChem and asserts equality with independent
PySCF LANL2DZ records before using it. Both atoms carry ECPs, with ionic
charges 1 and 7 and eight valence electrons. It preserves all 16 AOs before
canonical orthogonalization of the diagonal-normalized S at threshold
`1e-7`; the fit uses 240 unpruned def2-svp-jk auxiliary functions.

Regenerate in a separate PySCF process with:

```sh
"$VIBEQC_PYSCF_PYTHON" examples/regression/periodic_ecp_reference.py \
    --output /tmp/nacl-ecp-reference
```

The NPZ prefixes each component with `geometry_0_` or `geometry_1_`.
The JSON stores exact inputs, accepted energies and source hashes; the
`.system` identifies PySCF as the external reference program. The generator
also produces individual `pyscf.system` manifests. Independent repeated runs
agreed within 6e-9 Ha. These data alone do not establish native parity.
The old native test energy window remains unchanged pending the matched
one-electron and fit component diagnosis; it must not be repinned merely
to accommodate a changed native answer.

`nacl_ecp_projectors.npz` and its JSON record isolate eight Na/Cl projector
images against 16 home-cell bra and 16 displaced ket functions. The independent
PySCF 2.6.2 process uses a single real projector atom and four ghost basis
centers; it extracts only the bra/ket cross block. Regenerate with the same
external interpreter and script using `--projector-components`. Repeated
generation agreed exactly. NPZ SHA256:
`6640fc5483a97cf04e294b575e69dd060907fdc9a05635e6de57682070839c65`.

These matrices expose #758's six-digit generated angular coefficients and
primitive radial screening before ECP/translation-factor multiplication.
The worst pre-fix matrix error was 3.9966e-8. Independently coded s/p angular
projections followed by adaptive radial quadrature confirmed the largest
matrix-element discrepancies; the local potential agreed, while nonlocal
projectors did not. Full-precision generated coefficients and complete
primitive terms reduced all eight diagnostic matrix errors below 2.4e-13.
This component evidence does not establish periodic SCF or force parity.
