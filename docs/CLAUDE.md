# Claude Code instructions

Claude Code loads the repository root
[`CLAUDE.md`](https://github.com/vibe-qc/vibe-qc/blob/main/CLAUDE.md),
which imports the shared agent rules from
[`AGENTS.md`](https://github.com/vibe-qc/vibe-qc/blob/main/AGENTS.md)
and adds a few Claude-only notes.

Older pages cite "CLAUDE.md § N". Those sections belong to the monorepo's
`CLAUDE.md`, retained in the private historical archive, not current rules. The root `AGENTS.md` lists what changed from
them.
