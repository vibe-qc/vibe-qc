The rules for AI coding agents working on vibe-qc are in the repository root:
[`AGENTS.md`](https://github.com/vibe-qc/vibe-qc/blob/main/AGENTS.md).
[`CLAUDE.md`](https://github.com/vibe-qc/vibe-qc/blob/main/CLAUDE.md)
and [`CODEX.md`](https://github.com/vibe-qc/vibe-qc/blob/main/CODEX.md)

[`CONTRIBUTING.md`](https://github.com/vibe-qc/vibe-qc/blob/main/CONTRIBUTING.md),
[contributor setup](contributor_setup.md) and the
[release process](release_process.md).

Older pages cite "AGENTS.md rule N" or "CLAUDE.md § N". Those refer to the
monorepo's files, retained in the private historical archive. The current root `AGENTS.md` lists what changed from them.
