# Manrope artwork source

Unmodified variable font from [Google Fonts](https://github.com/google/fonts/tree/fb629caaa15ad25c051089c98f09cf6c8e30a86b/ofl/manrope),
commit `fb629caaa15ad25c051089c98f09cf6c8e30a86b`. Copyright 2018 The Manrope Project Authors.
Redistributed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt).

The generator turns typography into SVG paths. The font is build tooling,
not served to browsers or imported by any chemistry package.
